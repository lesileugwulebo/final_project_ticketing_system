# Changelog

All notable changes to the Verdad Tickets project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0-draft] - 2026-07-30

### Added
* Initial project proposal document conforming to MIVA MIT standards.
* Network and architectural designs including AWS-GCP VPCs and Site-to-Site VPN mapping.
* Relational 3NF MySQL database schema script and seed inserts.
* CSS typography styles token mapping variables.
* complete REST API endpoint endpoints registry inside FastAPI.
* Password hashing (Argon2id) and stateless JWT session auth validation layer.
* Seed database automation utility script.
